# José Marcondes — Portfolio

Modern personal portfolio website built to showcase my experience, projects and skills as a Software Developer.

The project was designed with a clean, modern and technology-focused interface, featuring an animated code editor inspired by development environments.

## 🚀 Technologies

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- Lucide Icons

## ✨ Features

- Modern dark UI design
- Responsive layout
- Animated code editor Hero section
- Component-based architecture
- Glassmorphism effects
- Smooth interactions and animations

- JavaScript
- React

Currently exploring modern web development and AI-powered development tools.
